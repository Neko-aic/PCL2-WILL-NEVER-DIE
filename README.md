# PCL2-WILL-NEVER-DIE

> “PCL2不会死！为了我们的自由，向着他们发动最后的进攻！” 

本仓库旨在作为 PCL2（Plain Craft Launcher 2）的**“火种”备份站**。在风暴降临之际，我们在此留存 PCL2 安装包，并提供**下载功能修复脚本**，以便大家能在离线或特殊网络环境下继续使用启动器。

星火不灭，备份长存。

---

## 📦 仓库内容

本仓库包含以下两部分核心内容：

1. **恢复下载脚本（分卷压缩包）**：用于修复/恢复启动器内置的下载功能。
2. **PCL2 老版本备份**：提供历史可用版本的存档（视上传进度而定）。
